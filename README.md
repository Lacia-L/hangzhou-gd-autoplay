# 杭州国动视频 自动刷课 (gdypt autoplay)

一个 Tampermonkey(油猴)脚本，自动把「杭州国动视频」学习平台(`gdypt.rf.hangzhou.gov.cn`)上**未学习**的视频逐个以 **1x 原速真实播放到结束**，使其状态翻转为「已学习」。装好后打开该网站、登录，页面右下角出现控制面板，点「开始」即可挂机。

> 平台会校验真实观看时长，所以只有 1x 原速播完整条才算数。**没有倍速/快进捷径。** 整个目录约 400 个视频、需数十小时真实时长——请用「目标数 / 截止时间」分批挂机。

## 安装（Edge / Chrome）

1. 安装扩展 **Tampermonkey**：
   - Edge 扩展商店搜索 “Tampermonkey”，或访问 https://www.tampermonkey.net/ 下载。
2. 打开 Tampermonkey 管理面板 →「实用工具」→「导入」，或直接「添加新脚本」，把本仓库的
   [`hangzhou-gd-autoplay.user.js`](./hangzhou-gd-autoplay.user.js) 内容粘贴进去并保存（Ctrl+S）。
   - 若本仓库已设为 GitHub 原始链接，也可直接访问 `.../hangzhou-gd-autoplay.user.js` 由 Tampermonkey 一键安装。
3. 打开并登录 `https://gdypt.rf.hangzhou.gov.cn` 的视频学习页面。
4. 页面右下角出现「国动自动刷课」面板 → 点「开始」。

## 使用

- **开始 / 暂停 / 停止**：控制当前挂机任务。
- **目标数**：本次还要刷够几条就自动停机（0 = 不限）。达到目标会**先把当前这条播完**再停，绝不打断。
- **截止**：到设定时间自动停机（同样是看完当前条才停）。适合睡前挂机、定个早上几点停。
- **打开页面后自动开始**：勾选后，以后一进该页面就自动开跑（偏好保存在本地）。
- **清除本地进度**：清空脚本记录的「已尝试 / 已完成」，让它重新扫描（不会取消已经学到的视频）。
- 进度会写入浏览器 `localStorage`，**刷新或重进页面不丢失**，脚本会自动接着上次继续。
- **倍速**：面板可下拉选择 1x / 1.5x / 2x / 3x / 4x（默认 1x，选择也会记在本地、状态栏实时显示）。⚠ 但平台按真实观看时长校验，**倍速很可能不被计入「已学习」**——除非你先拿一条实测确实能翻转，否则请务必保持 1x。

## 必须知道的前提与坑

1. **页面必须在前台可见。** 标签页一旦被浏览器判定为隐藏（`document.hidden = true`），视频会被强制暂停、进度不走。请让该浏览器窗口保持在最前面，不要最小化、不要锁屏。面板显示「⚠ 页面被隐藏，已暂停」就是碰到这个了。建议用双屏；单屏就把它一直搁在最前。
2. **倍速 / 拖进度条无效。** 平台按真实观看时长判定，只有 1x 完整播完才计入。
3. **大文件加载慢。** 单条可达上百 MB，开头需要 30–120 秒才开始播，属正常。面板会显示「加载中」。
4. **卡死自动跳过。** 某条视频若长时间（默认约 3 分钟）毫无播放进度，脚本会把它标记为已尝试并跳过，避免一条坏文件堵住整个任务。
5. **防休眠。** 挂机期间别让电脑睡眠（Windows 可用「电源设置 → 从不睡眠」，或第三方 caffeinate 类工具）。

## 选择器（前端构建带 hash，改版可能失效）

| 作用 | 当前值 |
|------|--------|
| 视频卡片 | `.unit-video-zUBDJE` |
| 已学习角标 | `.is-read-ejnl30`（存在即已学） |
| 卡片标题 | `.video-name-qEjzBZ` |
| 唯一 id 来源 | 卡片缩略图 `img[src*="getFileThumbnail/{id}"]`（去重键，退化到标题） |
| 弹窗视频 | `document.querySelector('video')`（src 为 `.../getFileStream/{id}`） |
| 关闭按钮 | `.ant-modal-close` |

若改版导致不生效，按上面的思路重新抓取 class：先在页面上找一个已学习卡片，定位那个「已学习」角标元素和卡片容器元素各自的 class，替换脚本顶部 `CFG` 里的 `CARD/READ/NAME` 即可。
